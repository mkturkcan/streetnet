Three commands take panoramas to an asset map and its evaluation

1streetnet detectGPU

Reads

A panorama index (pano_id, lat, lon, heading) and equirectangular JPEGs

Writes

det/<pano_id>.parquet

One process per GPU; a panorama whose file exists is skipped, so runs resume.

2streetnet mapCPU

Reads

The detection files of a run folder

Writes

map/<name>_assets.parquetmap/<name>_assets.geojson

One point per asset with class, support, confidence and position source.

3streetnet evalCPU

Reads

The map and reference points of the same classes (gt_key, lon, lat)

Writes

metrics.json

Precision, recall and F1 per class at 2, 3 and 5 m inside an evaluation region.
